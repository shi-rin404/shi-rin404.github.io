HLSL and Assembly Analysis

I analyzed the game's pixel shader structure and injected HLSL assembly into every pixel shader in the game without causing a crash.

Code Logic: The code selects an unused texture register and manages it through A general-purpose DirectX 11 modding tool. (bo3b/3Dmigoto on GitHub). If the reserved register is in use, the code reads a frame counter from the script and uses it to transition between two textures.

Fun Fact: I wrote the assembly code without AI assistance.
